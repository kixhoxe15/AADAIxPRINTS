AADAI PRINTS WEBSITE

All files are in ONE FOLDER.

Files:
app.py
index.html
logo.png
poster.png
products-card.png
AADAI-PRINTS-CATALOG.pdf
requirements.txt

LOCAL:
1. Open this exact folder in VS Code.
2. Terminal: pip install -r requirements.txt
3. Run: python app.py
4. Open http://127.0.0.1:5000

IMPORTANT:
The HTML uses direct same-folder filenames (logo.png, poster.png, products-card.png and AADAI-PRINTS-CATALOG.pdf), so it also works with VS Code Live Server and static hosting. No static/assets or templates folder is required.
